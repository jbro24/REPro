Root-cause classification
-------------------------
CASE C — OmniRoute search provider limitation.

Evidence:
1. Six distinct, bounded, realistic job queries were sent directly to the live
   /v1/search endpoint.
2. Every request reached duckduckgo-free successfully and returned HTTP 200.
3. Every response contained zero results, with no malformed-response or upstream
   failure error.
4. Therefore Career Commander received no candidate records to normalize, reject,
   deduplicate, persist, or analyze.
5. The application’s query generator is not the sole cause: the direct test used
   simpler queries than the fresh-profile queries and still received zero results.
6. The application’s validation is not the cause: validation runs only after a
   result exists, and there were no results in this run.
